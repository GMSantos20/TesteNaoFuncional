O que este teste avalia?

Fundamentação para o seminário

1. Disponibilidade (ISO/IEC 25010)

O endpoint GET /health atua como um probe de monitoramento. Quando o sistema cai, ele retorna HTTP 503 para que ferramentas de nuvem (Kubernetes, AWS) saibam que a instância está instável.

2. Usabilidade sob Falha (Heurísticas de Nielsen)

  • Sem Tela Branca: A aplicação não quebra com erro 500 nem dá crash no servidor.
  • Preservação de Dados: Se a anotação falhar ao enviar, o texto digitado permanece no campo para você não ter retrabalho.
  • Mensagens Claras: Explica o que houve em português claro, em vez de mostrar códigos confusos como ECONNREFUSED.
